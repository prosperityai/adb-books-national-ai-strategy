# National AI Strategy in Practice: Companion Toolkit

Tools and templates for the book *National AI Strategy in Practice: Compute,
Data, Talent and Regulation for Emerging Economies* by Prosperity Paul
(ADB Books, 2026).

The toolkit is for ministry, regulator and agency teams. You do not need
to be a programmer. Each tool reads a plain text file you can edit (YAML or
CSV), does simple, commented arithmetic, and prints tables you can paste
into a cabinet paper. Every output the book discusses is printed in the
book, so you lose nothing if you never run the code.

**All example figures are illustrative.** "Example Republic" is a fictional
country. Replace every number with your own evidence before using a result.

## What is here

| Folder | What it does | Chapter |
|---|---|---|
| `readiness/` | Six-pillar readiness scorecard (0-4 scale) and scorer with a ranked gap list | 2 |
| `portfolio/` | Scores AI use cases, places them in quadrants and sequences them into waves | 3 |
| `planner/` | Sizes compute from demand: tokens/s, GPUs, power, capex, opex, 5-year TCO, build vs rent, staff | 4, 5, 7 |
| `finance/` | Builds a five-year budget workbook by pillar and financing source, with live formulas | 10 |
| `kpi/` | KPI framework (input to impact) and a red/amber/green status report | 12 |
| `templates/` | Nine fill-in-the-blank documents (see below) | 1, 5-9, 11, 12 |
| `examples/` | The real output of every tool, regenerated by `make examples` | all |
| `tests/` | Automated checks of every calculation | - |

## Setting up

You need Python 3.13. Then, in this folder:

```text
python3 -m pip install PyYAML==6.0.3 openpyxl==3.1.5 pytest==9.1.1 ruff==0.17.1
make test        # check everything works
make examples    # run every tool; outputs go to examples/*.md
```

Without `make`, run the commands below one by one.

## The tools, with one example each

### 1. Readiness scorecard (Chapter 2)

Edit a copy of `readiness/example-assessment.yaml`: give each indicator a
score from 0 to 4 and note the evidence you saw. Level definitions are in
`readiness/scorecard.yaml`.

```text
python3 readiness/score.py readiness/example-assessment.yaml
```

Prints pillar scores, the weighted overall score and the ten gaps that cost
most points (weight x gap), each with the next level to aim for. For the
example: overall 1.55 out of 4 (39%); top gap "Strategy with costed actions".
Full output: `examples/readiness.md`.

### 2. Use-case portfolio (Chapter 3)

Edit `portfolio/use_cases.example.csv` (one row per use case; scores 1-5).

```text
python3 portfolio/score_portfolio.py portfolio/use_cases.example.csv
```

Prints each use case's score (0-100), quadrant (flagship, quick win, long
bet, drop) and wave, then a wave summary with costs. Use `--per-wave 3` to
change how many projects can start in one wave. Full output:
`examples/portfolio.md`.

### 3. Compute planner (Chapters 4, 5 and 7)

Edit `planner/assumptions.yaml`. Every number has a comment giving its
source, or is marked ASSUMPTION.

```text
python3 planner/compute_planner.py
python3 planner/compute_planner.py --scenario "Regional research hub"
```

For each scenario it prints demand, GPUs by pool (with headroom and a spare
server), power, capex, annual opex, five-year TCO, a build-versus-rent
comparison with the break-even utilisation, the engineers needed, and a
sensitivity table for GPU throughput. Full output: `examples/planner.md`.

### 4. Strategy budget (Chapter 10)

Edit `finance/budget_inputs.yaml`. Compute costs are pulled from the planner
automatically.

```text
python3 finance/build_budget.py
```

Writes `finance/strategy-budget.xlsx` (six sheets; all totals are Excel
formulas) and prints a summary by pillar and financing source. Full output:
`examples/budget.md`.

### 5. KPI report (Chapter 12)

Edit `kpi/kpi_framework.yaml` once, then each period fill in a values file
like `kpi/example-values.yaml`.

```text
python3 kpi/report.py kpi/example-values.yaml
```

Prints each KPI's progress against a straight line from baseline to target
and a status: GREEN, AMBER, RED or NO DATA. Full output: `examples/kpi.md`.

## Templates

| File | Use it to | Chapter |
|---|---|---|
| `strategy-on-a-page.md` | Summarise the strategy as a costed logic model | 1 |
| `data-centre-readiness-checklist.md` | Check a facility can power, cool and connect GPUs | 5 |
| `data-sharing-agreement.md` | Share data between public bodies lawfully | 6 |
| `civil-service-ai-curriculum.md` | Train civil servants by role | 7 |
| `algorithmic-impact-assessment.md` | Assess and tier a public AI system before use | 8 |
| `sandbox-application.md` | Apply to a regulatory sandbox cohort | 8 |
| `ai-procurement-clauses.md` | Protect the state in AI contracts | 9 |
| `delivery-unit-charter.md` | Set up the AI delivery unit | 11 |
| `five-year-review-tor.md` | Commission the independent five-year review | 12 |

The templates are drafting aids, not legal advice. Have counsel review any
agreement or contract clause before use.
